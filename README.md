# People Counter (Image-Only, YOLOv8)

A simple, accessible **image-only people counting tool** built with **Python, YOLOv8, and OpenCV**.

- ✅ Counts the number of people in a single image
- ✅ Uses pretrained YOLOv8 models (no training required)
- ✅ Works on standard laptops (CPU-only is fine, just slower)
- ✅ Easy to run and easy to extend
- ✅ Perfect for research, public policy, and demos
